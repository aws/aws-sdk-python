# Amazon Bedrock AgentCore Client

The `aws-sdk-bedrock-agentcore` package provides a client for making
requests to Amazon Bedrock AgentCore.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-bedrock-agentcore
```
