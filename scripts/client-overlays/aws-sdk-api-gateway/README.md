# Amazon API Gateway Client

The `aws-sdk-api-gateway` package provides a client for making
requests to Amazon API Gateway.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-api-gateway
```

- [API Reference](https://docs.aws.amazon.com/sdk-for-python/v4/reference/clients/api-gateway/) -
