# Connect Health Client

The `aws-sdk-connecthealth` package provides a client for making
requests to Connect Health.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-connecthealth
```
