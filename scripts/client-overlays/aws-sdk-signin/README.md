# AWS Sign-In Service Client

The `aws-sdk-signin` package provides a client for making
requests to AWS Sign-In Service.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-signin
```

- [API Reference](https://docs.aws.amazon.com/sdk-for-python/v4/reference/clients/signin/) -
