# Data Automation for Amazon Bedrock Client

The `aws-sdk-bedrock-data-automation` package provides a client for making
requests to Data Automation for Amazon Bedrock.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-bedrock-data-automation
```
