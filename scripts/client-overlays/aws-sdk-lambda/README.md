# AWS Lambda Client

The `aws-sdk-lambda` package provides a client for making
requests to AWS Lambda.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-lambda
```

## Documentation

- [API Reference](https://docs.aws.amazon.com/sdk-for-python/v4/reference/clients/lambda/) -
  the Lambda client, available operations, and types.
- [Developer Guide](https://docs.aws.amazon.com/sdk-for-python/v4/guide/) -
  configuration, authentication, and usage of the AWS SDK for Python v4.
