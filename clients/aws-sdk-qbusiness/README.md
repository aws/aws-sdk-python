# QBusiness Client

The `aws-sdk-qbusiness` package provides a client for making
requests to QBusiness.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-qbusiness
```
