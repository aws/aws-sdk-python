# Amazon Lex Runtime V2 Client

The `aws-sdk-lex-runtime-v2` package provides a client for making
requests to Amazon Lex Runtime V2.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-lex-runtime-v2
```
