# AWS Security Token Service Client

The `aws-sdk-sts` package provides a client for making
requests to AWS Security Token Service.

> **Note:** This SDK is experimental and in early development. Breaking changes
> may occur prior to the release of version 1.0.0.

## Installation

```bash
python -m pip install aws-sdk-sts
```

## Documentation

- [API Reference](https://docs.aws.amazon.com/sdk-for-python/v4/reference/clients/sts/) -

- [Developer Guide](https://docs.aws.amazon.com/sdk-for-python/v4/guide/) -
